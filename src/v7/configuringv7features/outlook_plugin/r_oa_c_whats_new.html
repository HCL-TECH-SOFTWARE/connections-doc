March, 2021 Release

Activities is a web-based collaboration tool for collecting, organizing, sharing, and reusing work related to a project goal. Use Activities to organize your team's work around project tasks, rather than around the many tools that you use to perform them. Members of an activity interact in an online location in which they create, collect, and share a set of ideas and resources to support a project goal. With Notes Social Edition Embedded Experiences Add-On, you can interact with Activities directly from your Notes client.

Recent enhancements to the Activities include:
  • Multi-tenant HCL Connections: Introducing support for HCL Connections multi-tenant environments. A new authentication method (OAUTH) had been added to support multi-tenant servers. Note: The Connections Notes Plug-in does not support multi-tenant external users.

For more exhaustive information about Activities in Notes Social Edition, see the HCL Connections section of the Help documentation.
