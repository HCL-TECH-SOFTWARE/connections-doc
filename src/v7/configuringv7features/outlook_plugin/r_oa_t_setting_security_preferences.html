Setting the authentication type

Use the Advanced Server Settings window to specify the authentication type to use when communicating with the HCL® Connections server.

Before you begin

By default, HCL Notes authenticates with the HCL Connections server using form-based authentication, which means it establishes trust by sending a Lightweight Third-Party Authentication (LTPA) token to identify itself. If your administrator has implemented an alternate authentication mechanism in the environment in which the HCL Connections server is running, you might be instructed to edit the advanced server settings.

The administrator can configure these settings using an administrative policy, so do not perform this task unless you are instructed to do so by your administrator.

About this task

To change the authentication type used to communicate with the HCL Connections server, complete the following steps:

Procedure

  1. From the Notes® menu, select File > Preferences.
  2. Click Connections, and then click the Advanced button.
  3. Select an authentication type from the following list of options:
    Java™ Form (default)
    Communicates using form-based authentication. This option is implemented by default.
    Tivoli® Access Manager Form
    Communicates using form based authentication on Tivoli Access Manager. Do not select this option unless you are advised to do so by your administrator.
    Site Minder Form
    Communicates using form based authentication on Computer Associates eTrust SiteMinder. Do not select this option unless you are advised to do so by your administrator.
    OAUTH
    Use this to connect to Connections multi-tenant configurations using OAuth. Do not select this option unless you are advised to do so by your administrator. Note: OAUTH is only support for Connections multi-tenant instances.
  4. Click OK, and then click OK again to save your changes and close the Preferences window.
