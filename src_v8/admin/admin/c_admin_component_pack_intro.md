# Administering Component Pack for Connections {#c_admin_component_pack_intro .concept}

Monitor the services for Component Pack for HCL Connections™ and troubleshoot issues.

-   **[Backing up and restoring data for OpenSearch indices](../admin/cp_config_os_backup_restore_data.md)**  
Back up and restore OpenSearch data from the HCL Connections™ Component Pack system that contains the Kubernetes master server. Because you are connected to the OpenSearch container, by default you have root access to run commands inside the container.
-   **[Administering MongoDB for Component Pack](../admin/inst_comp_pack_mongodb_admin.md)**  
MongoDB administration tasks include monitoring system health.
