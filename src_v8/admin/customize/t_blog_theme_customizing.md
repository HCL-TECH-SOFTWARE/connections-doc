# Changing the theme used in a blog {#t_blog_theme_change .task}

A theme controls the layout and color-scheme of your blog. When you create a new blog, you choose from one of the built-in themes.

You must be a blog owner or administrator to edit the blog theme.

**Note:** This application is disabled by default for blog users. To enable it for blog owners, site administrators must enable it on the Administration Configuration page. It's recommended that site administrators handle theme customization.

Change the theme to update the look of your blog.

1.  From the **My Blogs** page, click **Settings** for the blog you want to customize.

2.  Click **Theme**.

3.  Select a different theme for the blog.

    A preview window shows you what your blog will look like with the new theme.

4.  Click **Save** to apply the new theme.

5.  Select **Customize** to alter the theme for the selected blog.

    **Important:** Customizing a theme requires that you edit HTML template files. Do not customize unless you are comfortable working with HTML. When you click the **Customize** button the templates that define your current theme will be copied into your blog where you can edit them from the **Templates** page. Also note that you can only customize one theme at a time. Clicking **Customize** overwrites any previous customization.
