# Installing Community Surveys {#t_inst_installing_forms_experience_builder .task}

If you want to be able to conduct surveys within Communities to capture data and share it easily with your community in an activity stream, enable Community Surveys.

These topics include instructions on deploying the Surveys and Featured Survey widgets for Connections Communities.

When you integrate Community Surveys and Connections, you can add a survey widget to your Connections installation that can capture data and share it easily with your community in an activity stream.

Select the installation instructions for Community Surveys based on your existing system.

You must have WebSphere® Application Server and a database installed on your system for a production installation. Select the instructions to install Community Surveys with WebSphere Application Server.

If you do not have WebSphere Application Server installed on your system, select the instructions to install Community Surveys with WebSphere Application Server Community Edition. WebSphere Application Server Community Edition is intended for non-production uses, such as testing and development.
