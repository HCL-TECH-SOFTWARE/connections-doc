
# Connections Engagement Center (WebEngine) components

HCL Connections Engagement Center (WebEngine) provides a set of React-based components for displaying Connections content on portal pages. These components integrate with the Blueprint design system and use Social Rendering DDC for data retrieval.

## Available components

| Component | Description | Data Source |
|-----------|-------------|-------------|
| [CECMegaNews](./engagement-center-v2-components.md#cecmeganews) | Grid layout displaying news with hero emphasis | Connections Blogs |
| [CECNewsOverview](./engagement-center-v2-components.md#cecnewsoverview) | Flexible news list with row/column layouts | Connections Blogs |
| [CECFeaturedStories](./engagement-center-v2-components.md#cecfeaturedstories) | Carousel/slider for featured blog entries | Connections Blogs |
| [CECUpcomingEvents](./engagement-center-v2-components.md#cecupcomingevents) | Event list with filtering and pagination | Community Events |
